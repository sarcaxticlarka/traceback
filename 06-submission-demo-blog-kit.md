## Judge Q&A prep (rule 12: you must explain)

| Likely question | Answer shape |
|---|---|
| "What happens if you remove FalkorDB?" | Kill switch demo; list the three things that stop working (blast radius, ownership-as-of, handoffs) |
| "Why a graph rather than Postgres + recursive CTEs?" | Honest: you could, but traversal depth, per-agent-step latency, algorithms-as-tools (`pageRank`), and a graph per tenant in one instance are native here; show timings |
| "How does the verifier avoid LLM hallucinating entity names?" | Templates keyed by edge type; entity names compared to cited edges' endpoints; extras rejected |
| "How do you know the eval isn't rigged?" | Ground truth generated from the same generator, baseline gets same docs + same LLM; report where baseline wins; code in `eval/` |
| "How does handoff avoid two agents claiming the same task?" | Conditional `SET status='running' WHERE status='ready'`, check affected rows (explain the atomicity you actually tested) |
| "How is tenant isolation enforced?" | One graph per tenant; `g(tenant)` is the sole accessor; test asserts disjoint node IDs |
| "What did AI write vs you?" | Be exact; point to `AI_USAGE.md`; own the schema, verifier, eval |
| "What's synthetic?" | All of it; generator is deterministic, committed docs; no personal data |
| "What doesn't work yet?" | Name 2–3 limitations from README unprompted |
